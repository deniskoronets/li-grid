# Recipes

Copy-paste solutions for common tasks.

| Recipe | What you get |
|---|---|
| [API backend](./api-backend) | Load pages from your API and the response format it must return |
| [In-memory data](./client-side) | Filter, sort and paginate an array you already have, with no backend |
| [Row actions](./row-actions) | Edit / delete buttons per row, reloading the grid after a change |
| [Custom cells](./custom-cells) | Status badges, links, dates, images and header tooltips |
| [Dark mode toggle](./dark-mode) | Keep the grid in sync with your app's theme switch |
| [Auto refresh](./auto-refresh) | Reload the data every N seconds, pausing while the tab is hidden |
| [Custom look](./custom-look) | Brand colors, zebra rows, compact rows, your site's font |
